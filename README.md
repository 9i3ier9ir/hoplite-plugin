# Hoplite Plugin

Spigot/Bukkit plugin that manages up to four (or more) simultaneous death‑match games.
Players queue in lobbies, and when enough users are present the lobby is
converted into a battle arena generated by TerraformGenerator via Multiverse.

## Features

- **Configurable lobbies** – defined in `config.yml`. Defaults include ten
  worlds `qwait1` … `qwait10`, and you can add or remove entries.
- **Duos support** – configured per lobby with `mode: duos`. Queue with
  `/queue duos` or `/q duos`, and leave with `/leaveq` as usual.
- **Automatic world generation** using `/mv create <gameWorld> normal -g TerraformGenerator`.
- **Countdown logic**: 60‑second start when minimum players join, with
  warnings at 30s/10s; a full lobby switches to a 10‑second timer.
- **Shrink­ing world border**: starts at 1000 blocks and shrinks 10 blocks per
  minute once the arena is created.
- **Grace period support**: the first 5 minutes of a match are non-PvP, then the plugin sends players a `/msg` from console announcing that the grace period is over.
- **Tracking compass**: after 10 minutes of an active game, players receive a compass that tracks the nearest opponent.
- **Friendly-fire protection** in duos mode: teammates cannot damage each other.
- **Command blocking** inside active games (`You cannot use commands.` message).
- **ELO ranking and coin persistence**: ratings and coins are stored between
  restarts in plugin data files.
  - Use `/elo` to view your rating.
  - `/eloleader` shows the top‑10 leaderboard.
  - Use `/cbal` to view your coin balance.
  - `/cleader` shows the top‑10 coin leaderboard.
- **Queue commands**: `/queue` or `/q` will place you into an available lobby immediately if one is free. If all lobbies are full or active, you are placed in the global waiting queue and moved into the next available lobby automatically.

## Configuration

The default `config.yml` is included with these entries:

```yaml
lobbies:
  - lobbyWorld: qwait1
    gameWorld: game1
    maxPlayers: 10
    minPlayers: 5
  - lobbyWorld: qwait2
    gameWorld: game2
    maxPlayers: 20
    minPlayers: 10
    mode: duos
  - lobbyWorld: qwait3
    gameWorld: game3
    maxPlayers: 20
    minPlayers: 10
    mode: duos
  - lobbyWorld: qwait4
    gameWorld: game4
    maxPlayers: 10
    minPlayers: 5
  - lobbyWorld: qwait5
    gameWorld: game5
    maxPlayers: 10
    minPlayers: 5
  - lobbyWorld: qwait6
    gameWorld: game6
    maxPlayers: 10
    minPlayers: 5
  - lobbyWorld: qwait7
    gameWorld: game7
    maxPlayers: 10
    minPlayers: 5
  - lobbyWorld: qwait8
    gameWorld: game8
    maxPlayers: 10
    minPlayers: 5
  - lobbyWorld: qwait9
    gameWorld: game9
    maxPlayers: 10
    minPlayers: 5
  - lobbyWorld: qwait10
    gameWorld: game10
    maxPlayers: 10
    minPlayers: 5
```

Add additional items to the `lobbies` list (change world names as needed).
ELO ratings are stored in `plugins/<plugin>/elo.yml` and coins are stored in
`plugins/<plugin>/coins.yml` automatically; manual editing is not required.

## Commands

| Command    | Description |
|------------|-------------|
| `/queue` or `/q` | Join an available lobby or the waiting queue |
| `/queue duos` or `/q duos` | Join a duos lobby queue |
| `/leaveq` | Leave your queue |
| `/elo`     | Show your current rating |
| `/eloleader` | View the top‑10 ELO leaderboard |
| `/cbal` | Show your coin balance |
| `/cleader` | View the top‑10 coin leaderboard |
| `/coingive <player> <amount>` | Give coins to another player |
| `/k` | Open the kit shop menu |

## Build & Install

```bash
mvn package
```

Copy the resulting JAR into your server's `plugins/` folder. Ensure all
lobby worlds specified in `config.yml` already exist on the server. Make sure
Multiverse and TerraformGenerator plugins are installed as the plugin relies
on them at runtime.

> If you want PlaceholderAPI support during development, place the
> PlaceholderAPI jar file at `lib/PlaceholderAPI.jar` before building. The
> project is configured to resolve PlaceholderAPI from that local path.
>
> PlaceholderAPI placeholders provided by this plugin:
> - `%hoplite_elo%`
> - `%hoplite_coins%`
> - `%hoplite_inqueue%`
> - `%hoplite_queue_status%` (returns `singles`, `duos`, or `none`)
> - `%hoplite_ingame%` (returns `true` when the player is currently in an active game)
